# Bookstore DRF

Este projeto é uma aplicação Django REST Framework para gerenciar uma livraria.

## Funcionalidades
- Serializers para os modelos da aplicação
- Testes unitários para validar serializers e viewsets
- API REST para operações de CRUD
- Arquivo `requirements.txt` para instalação rápida das dependências
