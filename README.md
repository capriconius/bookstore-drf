# Bookstore DRF

Este projeto é uma aplicação Django REST Framework para gerenciar uma livraria, incluindo serializers, testes unitários e configuração de dependências.

## 🚀 Funcionalidades
- Implementação de serializers para os modelos da aplicação
- Criação de testes unitários para validar serializers e viewsets
- API REST para operações de CRUD
- Arquivo `requirements.txt` para instalação rápida das dependências

## 📦 Instalação
Clone o repositório e instale as dependências:
```bash
git clone https://github.com/capriconius/bookstore-drf.git
cd bookstore-drf
pip install -r requirements.txt
